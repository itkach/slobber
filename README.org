* Slobber
  Slobber is a web service that allows to find and retrieve content
  from [[https://github.com/itkach/slob][slob]] files. Slobber is written in Java.

  To build:

   #+BEGIN_SRC sh

     # clone slobj and slobber sources
     git clone https://github.com/itkach/slobj.git
     git clone https://github.com/itkach/slobber.git

     #build fat jar in slobber directory
     cd slobber
     ./gradlew uberJar

   #+END_SRC

  To run Slobber from the fat jar and have it serve a slob file located
  at /~/Downloads/enwiki-20230201.slob/:

   #+BEGIN_SRC sh
   java -jar build/libs/slobber-0.12-all.jar ~/Downloads/enwiki-20230201.slob
   #+END_SRC

  By default Slobber listens on port 8013 at 127.0.0.1
  interface. Specify /slobber.port/ Java property to start on a
  different port and /slobber.host/ to start on a different interface.

  To find keys starting with letter A:

   #+BEGIN_SRC sh
   curl "http://localhost:8013/find?key=A"
   #+END_SRC

  Use URLs specified in the return JSON document to retrieve content.

** Styles

  A =style= query parameter on a content URL makes Slobber apply that
  style to the HTML server-side, before the response is sent:

   #+BEGIN_SRC sh
   curl "http://localhost:8013/<slob-id>/<blob-id>?style=Night"
   #+END_SRC

  The style name is matched two ways:

  - Against the document's own *alternate stylesheets* - the classic
    "selectable alternate style sheets" convention
    (~<link rel="alternate stylesheet" title="...">~): the stylesheet
    whose title matches is enabled and the others disabled.
  - Against *user styles* - =.css= files you provide (see below): a
    =<link>= to that file is injected into the document.

  The chosen style is also propagated onto the document's internal
  (relative) links, so it stays in effect as cross-references are
  followed from one article to the next, with no client-side code.

*** User styles

   Point Slobber at a directory of =.css= files with the
   /slobber.styleDir/ property (embedders can call /setStyleDir/
   instead):

   #+BEGIN_SRC sh
   java -Dslobber.styleDir=~/my-styles -jar build/libs/slobber-0.12-all.jar ~/Downloads/enwiki-20230201.slob
   #+END_SRC

   Each =<name>.css= in that directory is then available - the file
   name (extension and all) is the style's name:

   - =GET /user-styles= returns a JSON list of the available style
     names, for a client's style picker.
   - =GET /user-styles/<name>= serves that style's raw CSS. It is
     revalidated with an ETag, so replacing the file serves the new CSS
     at once.
   - ~?style=<name>~ on a content URL serves the HTML with that user
     style linked in.
